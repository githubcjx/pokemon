# 《空间的形状》剧情草案 v1（代码短名 `space`）

2026-10-25。用户要求：接《时间的心跳》，讲空间和帕路奇亚，带一点帝牙卢卡；视觉上要有立体空间感，类似 React Bits 的炫酷效果，能直接用的组件就直接用；**前 3 秒必须抓住观众**；概念讲得通俗；按 `千年之后.mp3` 卡点。标题《空间的形状》，画风 A「全息维度」。

**逐句字幕、卡点、每段画面见 [space-texts.md](space-texts.md)。** 本文件记结构、原则、核实记录和画风。

## v0 → v1 改了什么（2026-10-25）

- 用户确认：按《千年之后》卡点（和上期同一个文件，153 秒，第 72 小节强拍结束）；概念要通俗，其余按 v0 的推荐办。
- 因此定下：不提骑拉帝纳；赤日不出形象，只出红色锁链；起源形态用官方立绘 `art-origin.png`（2026-10-26 用户要求不用 AI 图）。音效轨还没定。
- 片长从约 3 分半压到 2 分 33 秒，52 句改成 66 句短句（10-26 钩子链调整后加了第 4a 句，共 67 句，见 space-texts.md），每句一小节左右。
- **结构不再照搬上期**：上期是"一个概念 · 一段神话"固定交替，v0 也是这样；v1 改成一条故事线，首次显色提前到第 8 小节，爆发点改成赤日用红色锁链把时间与空间拽到一起对撞（人物推动冲突），再用"它们本是一块布"做反转。
- **科普改通俗**：去掉"可观测宇宙""角秒""超立方体""三维坐标"等说法，每个概念换成一个生活比喻、一两句带过——书页之间的缝、葡萄干面包、蹦床、折纸；尺度用"光一秒绕地球七圈半，横穿银河要跑十万年"；时空用"你看到的太阳是八分钟前的"。
- **官方原文只留 1 句**（"时间于是开始流动，空间于是开始扩张"），其余都按官方内容改写成旁白。
- 逻辑：不把现实物理说成枪之柱危机的原因；不说"差点毁掉世界的是两位神"（是赤日在利用它们的力量）。

## 前 3 秒的设计原则

1. **第 0 帧就在动**：不从黑场、空镜或 logo 淡入；第一帧网格已经在平移，第 1 句字幕从第 0 帧开始显现。
2. **0.1 秒内出现反常的画面**：第 0 小节强拍（第 3 帧）一道珍珠粉的裂痕闪过观众正在看的"屏幕"；1.15 秒（第 0 小节第 3 拍）裂痕炸开，两半画面往后翻开。全片最强的视觉概念放在最前面。
3. **第一句话对观众说"屏幕"，2 秒时抛出问题**（"如果有谁，能把空间撕开——"），答案（是谁、怎么做到）留到片中。
4. **单一视觉焦点、高反差**：深空黑底上只有一道珍珠粉的光，手机竖着刷也能一眼看清。
5. **3 秒内出现"宝可梦"信号**：第 2 小节第 3、4 拍，裂缝深处闪过两点粉光，排布和帕路奇亚肩上的两颗珍珠一致；只是光，叫声和名称卡留到第 8 小节显色时。
6. **声音和画面同一个起点**：裂痕落在配乐第 0 小节的强拍上。
7. **1.15 秒那一帧（屏幕裂成两半往后翻开）可以直接当封面**。

## 画风 A「全息维度」

- **颜色**：近黑的深空（带一点紫）为底；主色珍珠白 + 帕路奇亚的淡紫粉；辅色是上期帝牙卢卡的钴蓝，只在时间相关的地方出现；起源形态和"再生"时加一点创造神的金。
- **镜头**：全片用真 3D 相机（three.js / 着色器光线步进），景深、视差、色散。**环境可以大幅推拉环绕，宝可梦层保持接近正面**（转身角度不超过 ±7°），只跟镜头做小视差。
- **材质**：现实这一侧是发光线框和点阵（冷、清楚，数据看得清）；帕路奇亚出力时线框变成珍珠母贝的虹彩玻璃（这样"它在改变空间"一眼可见）。
- **质感**：胶片颗粒照技术约定（深底 0.12；浅色的方格网画面降到 0.06）。

### React Bits 组件的用法

调查结果（2026-10-25，`DavidHDev/react-bits` main 分支 `src/ts-default/`）：约 180 个组件里**只有 5 个用到 three.js**——Hyperspeed、Lanyard、ColorBends、BlobCursor（直接用 `three`），ModelViewer（R3F + drei）。**大多数背景和 3D / 粒子效果是手写的 WebGL2 着色器**（Galaxy、Particles、Ballpit、RippleGrid、GridScan、GridDistortion、LightRays、LightTunnel、Iridescence、LiquidChrome、Prism、PrismaticBurst、FluidGlass、GlassSurface、Cubes、InfiniteMenu、Antigravity 等），少数用 OGL（CrystalizedBall、RippleDistortion、WarpText 等），DomeGallery 是 CSS 3D 变换。许可证为 MIT + Commons Clause：可以用在我们的视频里，不能把组件本身转卖或再分发。

放进 Remotion 时都要移植：原组件用 `requestAnimationFrame` + `performance.now()` 驱动、带鼠标交互，渲染时每一帧不确定。做法是取出着色器 / 几何代码，时间改由 `useFrame()` 按整期时间轴驱动（`timeOffset`），去掉鼠标、随机数改成固定种子，走项目里已有的 WebGL2 写法（参照 `src/scenes/time/gl.ts`）；Hyperspeed 用 `@remotion/three`。移植的文件头注明出处和许可证。
