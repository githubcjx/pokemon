# 《敬畏》分段计划（代码短名 `regi`，输出 `out/敬畏/`）

脚本见 `script/regi-story.md`（v3，第 1–125 句）。整期用一条总时间轴（`src/scenes/regi/Master.tsx`），各段只是它的窗口（同《剑与盾》《人造容器》的做法），段落交界天然无缝。

## 画风：石与光点
- **基调**：深海的青黑、洞窟里水面反上来的青绿焦散光、遗迹里的暖琥珀色；全片唯一的强调色是**金色光点**。
- **母题：点**。点字、巨人脸上的七个点、遗迹地上的七个点、雷吉奇卡斯身上的七个圆孔，都画成会亮起的金色光点。凡是"被读懂 / 被唤醒"的东西，都以光点亮起表示。
- **宝可梦**：`PokemonArt3D` 2.5D，`depthScale` 约 0.5。光照跟场景走：石室里是水面反上来的青绿光加金色读字光，冰河是冷蓝轮廓光，地幔是从下方来的岩浆红光，神殿是雪光加火光。不打光时与原立绘一致。
- **点字用真的点字**：按游戏海外版的写法（英文一级点字，不加大写符号）逐格排出，读到哪一格，那一格上方浮出对应的字母。观众能看懂点字是怎么读的。
- **字幕**：`BiSubtitle` 默认色调；本期显现速度加快约 25%（`speed` 参数），每句停留按每秒约 6 个中文字计。名称卡用金色。
- **胶片颗粒** 0.12；画面偏暗，不需要降。

## 技术约定
- 时间轴：`src/scenes/regi/common.ts` 的 `T`（30fps 帧号），各段起点 `SEG_START`；合成 ID `REGI-<段名>`，另有 `REGI-Part1/2/3`（上中下篇）和 `REGI`（整期）。
- 石室用自写的 WebGL 舞台（墙面高度图做成纹理：石板、点字凸点、每格的阅读顺序都编码在里面，读字进度由 uniform 控制）；深海用全屏着色器；点阵片名和光点用 Canvas 2D。
