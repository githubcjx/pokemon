# 坠落的序列（代欧奇希斯）

短名 `deoxys`。加长版（2026-11-15）时长 3:24（6120 帧 @30fps 时间轴，60fps 渲染）；旧版 2:16 的成片留在 `out/坠落的序列/` 与 `重渲染-20261114-174308/`，加长版输出到 `out/坠落的序列/加长版-20261115/`。

## 画风：文字粒子宽银幕 · 冷调冥想

来源：用户提供的 `style-typographic-cinematic.md`。与 CLAUDE.md 冲突处的处理：

- 画幅：成片仍是 1920×1080 / 60fps（底线），画面内做 2.39:1 遮幅（上下各约 138px 的近黑条 `#07070C`），字幕放在下遮幅里。
- 配乐：风格文件的 drone 是可选项，按 CLAUDE.md 不做；只放叫声。
- 宝可梦：用官方立绘按网格采样成“文字粒子”的落点（`tools/glyph_points.py`），画面上只有字符，不出现立绘像素。

材质：海面、星空、极光、DNA 双螺旋、宝可梦、陨石、星图都由字符堆成——ATGC 碱基字母、腺/胸/鸟/胞、片假名デオキシス、Δ、星表式的数字。
暖色母题：一点琥珀色光（`#CBB084`）始终标着“代欧奇希斯在哪里”：开头的陨石 → 胸口的水晶体 → 坠向小岛的光点 → 黑石边缘 → 夜空里那颗会转向的陨石 → 流星雨夜空高处的一点。高潮（陨石被击碎、宇宙之战）玫瑰紫转金，之后回冷、回黑。

## 主线（全部依据游戏）

1. 陨石带着宇宙病毒坠落；病毒的 DNA 受激光照射突变，成为代欧奇希斯（图鉴）。名字取自 DNA 的全称（脱氧核糖核酸）。
2. 胸部水晶体好像是大脑；智商高、会超能力（图鉴）。四种形态，变换时出现极光（火红/叶绿/绿宝石图鉴）。
3. 各地的陨石能让它变换形态（帷幕市、关都 3 号道路、七宝市博物馆、古香镇化石研究所、秋叶镇、辉克拉尼天文台；朱紫起陨石成为道具）。
4. 诞生之岛（火红/叶绿/绿宝石）：要极光船票才能去，地图上原本没有；岛上只有一块黑色三角形石头，每调查一次就移位，沿最短路线追上才会逐渐变红，最后碎裂、出现代欧奇希斯。
5. EpisodeΔ：绿岭宇宙中心最先发现巨大陨石（直径超过十公里），它半路改变轨道直冲星球，研究员说“简直就像是活的一样”；流星之民早有预言；主角乘超级烈空坐击碎陨石；碎片中飞出三角形的东西，伸出触手爆开，现出代欧奇希斯，立刻开战（它的招式：精神增强、宇宙力量、自我再生、破坏光线）。
6. 危机过去：宇宙中心欢呼；那几天本来就有一场流星雨（EpisodeΔ 开头的新闻与双人票），主角和劲敌在宇宙中心的天体展览上看了流星雨。
7. 收尾：出现在极光的附近（心金/魂银、Y 图鉴）。

不讲的：剧场版《裂空的访问者》等动画设定；谁发射了激光、来自宇宙何处（游戏未交代）；陨石是否由代欧奇希斯操纵转向（游戏只说“像活的一样”，字幕不下结论）。
