# 《神奥之名》分段计划（代码短名 `hisui`，输出 `out/神奥之名/`）

字幕见 `script/hisui-texts.md`（102 句，用户 2026-10-24 确认）。整期一条总时间轴（`src/scenes/hisui/Master.tsx`），各段是它的窗口（同《敬畏》《剑与盾》），段落交界天然无缝。

## 画风 A「雪峰与天裂」（用户 2026-10-24 选定，要看立体 3D 场景）
- **真 3D 场景**：`@remotion/three`（参照《看不见的信任》的 `src/three/`）程序化建模，不用外部模型：
  - 天冠山山顶：雪峰地形（程序生成高度场 + 雪面材质 + 风吹雪粒子），远处群山与云海。
  - 神奥神殿：照游戏（《传说 阿尔宙斯》）的样式建模，完好 / 炸毁 / 今天的枪之柱三个状态共用一套几何，崩塌是真实的三维碎裂镜头。参考图在 `assets-src/hisui-ref/`（只作建模参考，不进成片）：
    - 完好（`temple-of-sinnoh-la.jpg`）：希腊式白色大理石神殿，阶梯式台基，带凹槽的圆柱（柱身有蓝色和金色的环带），三角山墙正中一枚金色徽记，宝可梦石像立在柱间的方形底座上。
    - 废墟 / 枪之柱（`spear-pillar-art.jpg`，钻石·珍珠的设定图）：方形石台上一片高低不齐的断柱，不少断口削尖像枪头，还剩几道残拱和散落的碎石。按 Bulbapedia，洗翠的神殿被毁后就是这个样子。
    - 其余细节有出入时请用户给游戏截图。
  - 十尊石像：由十只宝可梦的官方立绘推算成石雕（立绘的深度图挤出浮雕体 + 石材着色，不手画造型），立在神殿里，崩塌时一起碎。
  - 祝庆村、海滩、吾思的小屋：远景剪影级别的简单建模。
  - 镜头可以真 3D 环绕、升降；宝可梦出场时回到正面再用 `PokemonArt3D` 合成（`projectToScreen` 换算位置），立绘本身不做大角度旋转（yaw / pitch ≤ ±7°）。
- **着色器**：天空裂缝（照游戏：紫灰天幕上一团白蓝的强光核心，向四周炸出闪电状的裂纹，`rift-la.jpg`）、红色天幕（异变，`red-sky-la.jpg`）、落雷、光之阶梯、阿尔宙斯的金光。
- **颜色线**：开场今天的冷月光 → 古代的暖石色 → 金刚队深蓝带金 / 珍珠队珍珠白带粉两种光 → 裂缝的紫灰天幕与白蓝裂光 → 异变的红天 → 起源形态的强光 → 阿尔宙斯的金白 → 回到冷月光。
- **宝可梦**：`PokemonArt3D`，`depthScale` 约 0.5；光照跟场景走（月光冷轮廓、雪地反光、裂缝的红紫从上方、阿尔宙斯自身发光）。王和湖之三神只做剪影。
- **人物**：官方立绘压成带微光的黑色剪影（马加木、刚石、珠贝、望罗、吾思、拉苯、主角明耀；开场和结尾的赤日）。没有官方形象的人（古人、部族成员、银河队队员）用代码画剪影。
- **字幕**：`BiSubtitle speed={1.25} sync scale={1.12} enStrong`——中英同时从左到右显现，字号比以前大 12%，英文加粗提亮（用户 2026-10-24 要求）。名称卡金色。
- **胶片颗粒** 0.12；雪地和金光等浅色画面降到 0.06（CLAUDE.md）。

## 技术约定
- 时间轴：`src/scenes/hisui/common.ts` 的 `T`（30fps 帧号）、各段起点 `SEG_START`；合成 ID `HISUI-<段名>`，另有 `HISUI-Part1/2/3`（上中下篇）和 `HISUI`（整期）。
- 3D：`src/three/` 下新建 `coronet.tsx`（山顶地形、云海、风雪）、`temple.tsx`（神殿三态与崩塌）、`statues.ts`（立绘 → 石雕）；镜头与布光沿用 `stage.tsx` 的做法。
- 着色器：`src/scenes/hisui/gl.ts`（裂缝、红天、落雷、光阶、金光）。
- 叫声：帝牙卢卡 `dialga.ogg`、帕路奇亚起源形态 `palkia-origin.ogg`、骑拉帝纳 `giratina.ogg` / `giratina-origin.ogg`、阿尔宙斯 `arceus.ogg`。
- 先做 3D 测试片 `TEST-Hisui3D`（山顶 + 神殿完好 → 崩塌 → 枪之柱）给用户看方向，再正式做第 1 段。
