片名：《被遗忘的英雄》/ THE FORGOTTEN HEROES（用户 2026-11-13 同意）　代码短名：`galar`
- 画风：中世纪挂毯刺绣（用户 2026-11-13 选定）。参照宝物库挂毯（原型巴约挂毯）：羊毛织纹、针脚勾线、土红 / 靛蓝 / 赭黄 / 亚麻底；闇夜时黑红色从织物里渗出、把布撕开。
- 范围：闇夜与双英雄为主线；西索双人组只用一句带出"谁才是英雄"的争议（用户 2026-11-13："对观众理解有帮助就可以加"）。

- 资料与原文核实见 [galar-research.md](galar-research.md)。英文字幕表 `galar-texts.md` 在做每段时同步出。

## 在编年史里的位置
两万年前坠落的星，三千年前的闇夜。和《永恒之花》的卡洛斯战争同在约三千年前，两件事在游戏里没有直接关联（ＡＺ目击闇夜一说待核，核实前不提）。

## 主线
观众跟着一个问题走：**挂毯上画的英雄，是谁？**
挂毯 → 星的坠落 → 闇夜 → 剑与盾其实是宝可梦 → 一起击退闇夜 → 人成了王、宝可梦睡进森林 → 故事越传越少，宝可梦被抹去 → 索妮亚把它们找回来 → 有人不肯承认 → 第五张挂毯给出答案。

**"原来如此"的点**：①挂毯第三幅里驱散灾厄的是"剑与盾"，年轻人只是在看；②"一位英雄"的金像，是传说被删掉一半之后的样子；③第五张挂毯上"失去了剑与盾的两位英雄"，失去的不是武器，是两只宝可梦；④那张挂毯不在宝物库，流落到古董市场，最后挂在一家餐厅里。
