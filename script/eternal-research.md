## 官方中文名
ＡＺ（全角，中日同名）、花叶蒂（No.0670 · 单朵宝可梦 / Single Bloom Pokémon）、花蓓蓓（No.0669）、永恒之花、卡洛斯、密阿雷（市）、最终兵器、棱镜塔、昂主、旅馆Z、超Z队、ZA登峰战。
石香镇（Geosenge Town）、10号道路是 52poke 译名，XY 无官方中文，片中尽量不出现地名。

## XY 剧情要点（英 / 日原文）
- 弗拉达利研究所，ＡＺ的讲述：一个男人和一只宝可梦，他非常爱它 → 战争开始，它被用于战争 → 数年后，他得到了一个小小的箱子（日：小さな 箱を 渡された）→ 无论如何都想让它复活，造出给予生命的机器 → 复活了它 → 悲伤太深、愤怒未平，不能原谅伤害它的世界 → 把机器变成最终兵器，成为破坏之神，结束战争 → 被给予永恒生命的宝可梦"早已知道吧"，为了复活它牺牲了许多宝可梦 → 复活的宝可梦离开了男人。
- 石香镇：男人既惊讶又悲伤，"明明是为了再见面才让它复活的……"；见不到的日子一天天过去，他失去了心；被兵器之光照过的男人永远流浪，同样在永恒时间里流浪的还有那只宝可梦；"它现在在哪里？怎样才能见到它？"
- 第 13 号道路初见："宝可梦……花朵宝可梦……被给予了永恒生命的……"
- 密阿雷（成为冠军后的仪式）：战斗前"与我战斗吧。我想知道所谓训练家是什么"；战斗后"谢谢你与我战斗。终于舍弃了……造出最终兵器、被悲伤囚禁的自己"（日：ようやく 自分を 捨てられた）；花叶蒂从天而降，ＡＺ跪下；"花叶蒂……3000年了啊……"
- Celosia（闪焰队干部）：10 号道路排列的石头其实是宝可梦的墓，最终兵器结束战争时夺走了它们的生命。
- 最终兵器的形状像永恒之花（52poke 最终兵器页）。
- 弗拉达利是ＡＺ弟弟的后代（Z-A）；弟弟后来把兵器埋进地下（XY 弗拉达利研究所文件）。

## 传说 Z-A 官方中文（简体，摘自 52poke「ＡＺ」页）
屋顶自白：
- 接下来要说的是我曾犯下的罪孽……以及悔恨不已的故事。
- 3000年前的那场战争夺走了很多东西。
- 各种宝可梦的未来……很多人的日常生活……
- 我的花叶蒂也被赶上战场……失去了性命。
- 为了让我心爱的花叶蒂起死回生，我制造了能够赋予生命的机器。
- 花叶蒂复活了。我又让心爱的宝可梦回到了身边。
- 然而我的愤怒并没有平息。我没能原谅这个伤害了我心爱宝可梦的世界。
- 我在愤怒之下，把机器改造成了最终兵器。
- 为了彻底终结妄图掠夺一切的愚蠢战争，我选择让自己变成了破坏之神。
- 最终兵器发射出来的光芒直冲云霄，又洒落大地，将地表烧为焦土。
- 但花叶蒂应该是知道的。我赋予它的生命是从其他宝可梦那里夺来的。
- 花叶蒂不知去了哪里，而被留下的我漂泊了长达3000年。
- （昂主）我思考了一番，觉得这不能是用来掠夺的存在。而应该是一个能把获得永生的花叶蒂的力量分给大家的存在。
- 昂主成为了花叶蒂获得永生之后活下去的意义，也是我以我的方式对花叶蒂的一种赎罪。
- 我梦想过有一天能和花叶蒂重逢，然后启动昂主……这一天始终没有到来，但这也意味着世界是和平的。
- 时隔3000年的重逢应该代表着花叶蒂原谅了我……
其他：
- 被一瞬间的愚蠢情感所左右，结果竟让我悔恨了长达3000年……
- 3000年前的愚蠢情感，还有3000年前那太过愚蠢的行为。让我无法再见到心爱的花叶蒂。
- 这里对我来说是人生最后的住处，这就是旅馆「Z」的意义。
- 因为有宝可梦在身边，我才能更容易地和别人搭话……也就是说，宝可梦给了我认识世界的契机。
- 千万不要勉强宝可梦。要挽回失去的信任可不是件容易的事……
- 我活了足足3000年，身体到处似乎都有毛病了。
- 花叶蒂。把你那被称为永恒之花的力量借给超Z队吧。

墓志铭（简体）：
> 他知晓起始与终结，获得了3000年的寿命，却从未与他人有过生命的交集。直到在密阿雷遇到挚爱的宝可梦和值得信任的人们，他的生命才得以完整。男人名为ＡＺ，长眠于此。

遗书（英文，无官方中文）：临终回忆母亲把抱着罕见黑花的花叶蒂交给他、战火夺走一切、初见超级进化的惊喜、遇见卡洛斯的传说宝可梦、伽勒尔的暗夜；"过去的一切都会消失。这些记忆会淡去，我也一样。"

## 图鉴（官方中文）
- 究极之日（永恒之花）：它拿着的花，现在任何地方都没有在开放。而且被认为蕴藏着恐怖的力量。
- 究极之月（永恒之花）：那朵不祥的花里蕴藏着恐怖的能量，但它却天真地挥舞着那花。
- 传说 Z-A（永恒之花）：抱着在远古灭绝的植物，是十分罕见的花叶蒂。据说隐藏着强大的力量。
- 传说 Z-A（超级花叶蒂）：永恒之花会将超级进化的能量吸尽。花可以独自袭击敌人。
- 究极之日（花蓓蓓）：如果没有花的力量，就会很危险。但是在找到喜爱的颜色和形状之前，会不断地旅行。
- 传说 Z-A（花叶蒂·蓝花）：只要发现枯萎的花草就会带回自己的地盘照料，使其恢复活力。

## 其他事实
- 花叶蒂是ＡＺ的母亲送给他的（Z-A 遗书；增田顺一接受 Game Informer 采访时也这么说）。
- 永生和三米身高都来自最终兵器的能量（采访；XY 台词"被兵器之光照过"）。
- 3000 年间：目睹伽勒尔的暗夜；1000 年前在丰缘看到烈空坐平息原始固拉多 / 原始盖欧卡（ORAS 德尔塔篇，"来自远方的高大旅人"），在原始洞穴前种树，树下开着永恒之花同种的花；2000 年前应掌权者之托造昂主，藏进棱镜塔。
- Z-A 结尾：ＡＺ自然老死（画面外），超Z队在安息墓地祭拜；花叶蒂交给盖伊 / 塔霓，最后交给主角。
- 动画：TV 动画没讲；《宝可梦 Generations》第 18 集 "The Redemption" 讲过（往事 + 冠军游行对战 + 重逢）。
