## 和《时间的心跳》的结构区别

- 上期是"一个概念 · 一段神话"的固定交替；这期是**一条连续的故事线**：帕路奇亚先登场 → 带着观众认识空间（科普只当路标，一个比喻一两句）→ 它真正的力量 → 有人想夺走这股力量（赤日，人物推动冲突）→ 时间与空间对撞 → "原来它们本是一块布"的反转 → 回到开场的屏幕。

## 音效轨（2026-10-26）

用户要求重新创作、不参考旧期。全部用 `tools/space_sfx.py` 现场合成（numpy / scipy，不用任何素材），时间点按小节 / 帧号和画面常量对齐。输出 `out/空间的形状/space-sfx.wav`（整期，从第 0 帧对齐）和 `sfx/space-part{1,2,3}-sfx.wav`（按三篇切开），48 kHz 立体声，峰值 −1 dBFS。

- 声音的对应：空间 = 玻璃、铃、光尘；被撕开时是撕裂 + 碎玻璃。时间 = 低沉的脉冲、心跳（只在帝牙卢卡相关处）。镜头运动 = 带通噪声的呼啸，速度越快越亮。
- 叫声在视频轨里：显色那一下（8.0、30.0、52.0、53.0）音效只用超低频和极高频，让出中频。
- 最响的是第 53 小节对撞，其次是开场裂开（0.2）、墙炸开（16.0）、起源形态（30.0）、亚空裂斩（35.0）、画面被撕开（54.0）。第 40–41、68–70 小节有意留白。
- 结尾最后 0.7 秒淡到无声，循环回开场第 3 帧的裂痕声。
